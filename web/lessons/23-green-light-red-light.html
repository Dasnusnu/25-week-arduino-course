WEEK 23 · MAKE STATUS EASY TO SEE

Green Light, Red Light

Build two tiny LEDs that make a classroom or lab/demo status easy to notice—without controlling a door, lock, relay, or anyone’s access.

← All lessons

Your goal

Wire a green LED and a red LED to two Arduino output pins. Then use a single Serial Monitor letter to show a practice “ready” or “try again” status. This is a lab/demo status indicator, not an access-control system.

Time: 30–40 min
Difficulty: two LED branches
Output: one clear status light

Gather the parts

  • Uno-compatible board and USB cable
  • Breadboard
  • One green LED and one red LED
  • Two 220 Ω resistors
  • Six male-to-male jumper wires

Safety and meaning boundary: unplug USB before moving wires. LEDs have direction and each LED needs its own 220 Ω current-limiting resistor; never share one resistor between the two branches or omit either resistor. This is USB-powered, low-voltage classroom feedback only. Stop if a part is hot, damaged, or smells unusual. Do not use this lesson to unlock a door, operate a real lock or relay, make access decisions, judge a person, or signal that an RFID card is authorized. A green or red LED is only a practice message chosen in software—not proof of identity, permission, or safety.

Build it, one check at a time

Step 1 — Learn the shape of one safe LED branch

An output pin sends a small signal through an LED and a resistor to ground. The Freenove reference below shows that shape with a 220 Ω resistor and one LED. This lesson repeats that same safe pattern twice: once for green and once for red. The picture is a reference for one branch, not a diagram of this lesson’s complete two-LED circuit.

Step 2 — Identify LED direction

Find the two leads on each loose LED. Usually the longer lead is the anode (positive side) and the flat edge on the rim marks the cathode (negative side). Those are helpful clues, not a substitute for checking your part’s documentation. Put the red and green LEDs in separate breadboard rows so their legs do not accidentally touch.

Step 3 — Wire two independent status branches

With USB still unplugged, make these exact connections. The pin choices are intentionally ordinary digital output pins on an Uno-compatible board; they are a new two-LED teaching arrangement based on the reference’s one-LED branch pattern.

  • Arduino D5 → green LED anode
  • green LED cathode → 220 Ω resistor → Arduino GND
  • Arduino D6 → red LED anode
  • red LED cathode → 220 Ω resistor → Arduino GND

A resistor may be on either side of an LED electrically, but keep this order while you are learning to trace the circuit. Both branches may meet at the Arduino GND pin, but do not connect D5 to D6 or join the LED anodes. If an LED is dim, backward, or does not light, unplug USB before inspecting it.

Step 4 — Upload a manual practice-status sketch

Reconnect USB, select your board and port, upload this original teaching sketch, then open Serial Monitor at 9600 baud. Type g to show green (“ready”) or r to show red (“try again”), then send it. The code changes only the LEDs. It reads no RFID tag, stores no UID, checks no allow list, and controls no actuator. We use manual letters so the person at the computer chooses a harmless practice message rather than pretending a card scan proves authorization.

const byte greenPin = 5;
const byte redPin = 6;

void showGreen() {
  digitalWrite(greenPin, HIGH);
  digitalWrite(redPin, LOW);
}

void showRed() {
  digitalWrite(greenPin, LOW);
  digitalWrite(redPin, HIGH);
}

void setup() {
  Serial.begin(9600);
  pinMode(greenPin, OUTPUT);
  pinMode(redPin, OUTPUT);
  showRed();
  Serial.println(F("Type g for green (ready) or r for red (try again)."));
}

void loop() {
  if (Serial.available() > 0) {
    char choice = Serial.read();
    if (choice == 'g') {
      showGreen();
      Serial.println(F("Green practice status"));
    } else if (choice == 'r') {
      showRed();
      Serial.println(F("Red practice status"));
    }
  }
}

Step 5 — Test both messages, then reset safely

Send g once and check that only the green LED lights. Send r once and check that only the red LED lights. If both light, neither lights, or the colors are swapped, unplug USB before checking LED direction, D5, D6, both 220 Ω resistors, and the ground paths. When finished, send r or unplug USB. If you later connect this display beside your Week 22 scanner, keep it a visible lab/demo message selected by a supervised activity—never use it to decide entry or move hardware.

Tiny challenge

Add a third Serial Monitor letter, o, that turns both LEDs off. Explain why “off” can be clearer than guessing when a practice activity has not chosen a status yet.
