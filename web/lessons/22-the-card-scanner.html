WEEK 22 · NOTICE, DON’T UNLOCK

The Card Scanner

Read the public ID number from a card or key fob that you own, using an RC522 reader and Arduino Uno.

← All lessons

Your goal

Wire the RC522 by SPI, then print the UID of a user-owned or lab RFID tag in Serial Monitor. This is an observation-only scanner: it does not unlock, control, copy, write, or change any tag.

Time: 35–50 min
Difficulty: careful SPI labels
Output: a UID in Serial Monitor

Gather the parts

  • Uno-compatible board and USB cable
  • RC522 / MFRC522 RFID reader breakout with its antenna board
  • One RFID card or key fob that you own or are explicitly authorized to use in a lab
  • Breadboard and seven male-to-male jumper wires

Safety and permission boundary: unplug USB before moving wires. Power the RC522 from 3.3 V only, exactly as its label and the reference wiring table show—do not connect it to 5 V. Do not touch the antenna with loose metal while powered, force connectors, or continue if a part gets hot, is damaged, or smells unusual. A UID is an identifier, not a secret password and not proof that a card is authorized. Scan only user-owned or lab RFID tags with clear permission. Do not use this lesson to clone, write, alter, bypass, unlock, or test access cards, transit cards, school/work badges, hotel keys, payment cards, or any other tag you do not own and control.

Build it, one check at a time

Step 1 — Read the source table, then find your labels

The RC522 uses the Arduino Uno’s hardware SPI pins. On many RC522 breakouts the chip-select label says SDA; in this lesson it means the SPI select pin, not the Uno’s I²C SDA pin. Find the printed labels on your own module before wiring. Leave the IRQ pin unconnected for this read-only sketch.

Step 2 — Make the seven reader connections

With USB still unplugged, wire the exact RC522/SPI portion of the retained MIT reference. Read each label rather than guessing from the position of a header pin:

  • RC522 3.3V → Arduino 3.3V
  • RC522 GND → Arduino GND
  • RC522 SDA (SS) → Arduino D10
  • RC522 SCK → Arduino D13
  • RC522 MOSI → Arduino D11
  • RC522 MISO → Arduino D12
  • RC522 RST → Arduino D9

Do not add the retained project’s servo, LCD, or any lock hardware in Week 22. If your board is not Uno-compatible, do not assume these SPI pins apply; use that board’s documented SPI pinout and stop here until you can verify it.

Step 3 — Install one library

In Arduino IDE, open Library Manager and install MFRC522 by GithubCommunity. The maintained public MFRC522 library documents the SPI reader workflow and its “DumpInfo” example; this original, smaller sketch only detects a new card and displays its UID. It does not authenticate to blocks, read card memory, write card memory, or issue an access decision.

Step 4 — Upload the read-only UID viewer

Reconnect USB, select your board and port, upload this original teaching sketch, then open Serial Monitor at 9600 baud. The `PICC_IsNewCardPresent()` and `PICC_ReadCardSerial()` checks prevent output until a nearby tag is detected. The loop prints the UID bytes in hexadecimal, then sends the tag a halt command so the next presentation can be noticed. It contains no write, clone, access-control, servo, or relay code.

#include <SPI.h>
#include <MFRC522.h>

const byte ssPin = 10;
const byte resetPin = 9;
MFRC522 rfid(ssPin, resetPin);

void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  Serial.println(F("Present your own or lab RFID tag."));
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial()) return;

  Serial.print(F("UID:"));
  for (byte i = 0; i < rfid.uid.size; i++) {
    if (rfid.uid.uidByte[i] < 0x10) Serial.print('0');
    Serial.print(rfid.uid.uidByte[i], HEX);
  }
  Serial.println();
  rfid.PICC_HaltA();
}

Step 5 — Scan only your practice tag

Hold your authorized card or fob flat and close to the reader antenna for a moment. You should see `UID:` followed by hexadecimal characters. The exact UID length and digits vary by tag; do not publish someone else’s UID. If nothing prints, unplug USB before checking 3.3 V, GND, SDA/D10, SCK/D13, MOSI/D11, MISO/D12, RST/D9, library installation, and your board selection. Try the library’s documented diagnostic example only with your own/lab tag. A UID read is not a dependable security check, so do not use it to protect a real door or decide access.
