WEEK 24 · NOTICE, DON’T DECIDE

The Access System

Combine your RC522 reader and LCD into a lab-only screen that notices a tag you own and shows a harmless practice message.

← All lessons

Your goal

Use the retained MIT project’s RC522 and LCD wiring to display “Tag seen” after scanning a user-owned or lab RFID tag. This is a status/output simulation, not an access-control system: it does not identify a person, compare a UID, keep an allow list, unlock anything, or control any real door.

Time: 45–60 min
Difficulty: two connected modules
Output: a 16×2 practice status message

Gather the parts

  • Uno-compatible board and USB cable
  • RC522 / MFRC522 RFID reader breakout with antenna board
  • I2C LCD1602 module with a four-pin I2C backpack
  • One RFID card or key fob that you own or are explicitly authorized to use in a lab
  • Breadboard and eleven male-to-male jumper wires

Safety and permission boundary: unplug USB before moving wires. Power the RC522 from 3.3 V only; never connect it to 5 V. The LCD source connection uses 5 V. Check every printed label, keep metal away from the powered reader antenna, and stop if a part gets hot, damaged, or smells unusual. Scan only user-owned or lab RFID tags with clear permission. Do not use this lesson to clone, write, alter, bypass, unlock, test, or make decisions about any access credential; do not connect a servo, relay, lock, latch, door, gate, or other actuator.

Build it, one check at a time

Step 1 — Separate the source project into safe pieces

The retained MIT source connects an RC522, a 16×2 I2C LCD, and a servo. We will use only its published reader and screen connections. The source project later compares a UID and moves a servo; this lesson deliberately excludes those parts. Our screen will say only that a practice tag was noticed. It never labels a tag “authorized” or “denied.”

Step 2 — Wire the reader exactly

With USB still unplugged, follow the retained source’s RC522-to-Uno table. On many RC522 boards, SDA means SPI select here, not the Uno’s I²C SDA pin. Read your breakout’s labels rather than guessing from header position. Leave IRQ unconnected.

  • RC522 3.3V → Arduino 3.3V
  • RC522 GND → Arduino GND
  • RC522 SDA (SS) → Arduino D10
  • RC522 SCK → Arduino D13
  • RC522 MOSI → Arduino D11
  • RC522 MISO → Arduino D12
  • RC522 RST → Arduino D9

These Uno SPI pins are specific to this board family. If your board is not Uno-compatible, stop and verify its documented SPI pins before continuing.

Step 3 — Add the four-wire screen

Use an I2C LCD1602 with a four-pin backpack, not a bare 16-pin LCD. The retained source’s LCD table gives these exact Uno paths:

  • LCD VCC → Arduino 5V
  • LCD GND → Arduino GND
  • LCD SDA → Arduino A4 (SDA)
  • LCD SCL → Arduino A5 (SCL)

The reader’s `SDA` label and the LCD’s `SDA` label describe different interfaces, so they do not go to the same Arduino pin. On a classic Uno, the LCD’s I2C signals use A4 and A5. If the screen’s labels or your board differ, check its documentation before applying power.

Step 4 — Upload a notice-only scan sketch

In Arduino IDE, install MFRC522 by GithubCommunity and the LiquidCrystal_I2C library supplied for your LCD/kit. Reconnect USB, select your board and port, upload this original teaching sketch, then open Serial Monitor at 9600 baud. The source project uses `0x27`, 16 columns, and 2 rows; this sketch keeps that display setup and scan flow, but removes its UID comparison and all servo code. It prints no UID and shows only a practice status.

#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const byte ssPin = 10;
const byte resetPin = 9;
MFRC522 rfid(ssPin, resetPin);
LiquidCrystal_I2C lcd(0x27, 16, 2);

void showWaiting() {
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Show practice tag");
  lcd.setCursor(0, 1);
  lcd.print("Lab demo only");
}

void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  lcd.init();
  lcd.backlight();
  showWaiting();
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial()) return;

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Tag seen");
  lcd.setCursor(0, 1);
  lcd.print("Lab demo only");
  Serial.println(F("Practice tag noticed."));
  delay(1500);
  showWaiting();
  rfid.PICC_HaltA();
}

The message is intentionally not a permission result. This code has no stored UID, matching loop, card-memory command, display of a UID, actuator library, servo pin, relay pin, or door command.

Step 5 — Observe the practice notice

Hold your own/lab tag flat near the reader. The LCD should briefly show Tag seen and Lab demo only, then return to its waiting message. If the LCD backlight is on but letters are missing, unplug USB before gently adjusting its contrast screw or checking its documentation. If no scan is noticed, unplug USB before checking the seven RC522 wires, four LCD wires, library installation, and board selection. Do not replace this message with an approval, denial, name, identity, entry decision, or a command to real hardware.

Tiny challenge

Change the waiting message to another 16-character-or-fewer reminder about the lab boundary. Explain why “tag seen” is an observation while “allowed in” would be a decision this project must not make.
