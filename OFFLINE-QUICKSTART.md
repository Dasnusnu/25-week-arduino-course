# Offline quick start

1. Extract `25-week-arduino-guide-offline.zip` to a folder you can find again.
2. Double-click `START-HERE.html`.
3. If asked, open it in a modern browser such as Chrome, Edge, Firefox, or Safari.

No installation, terminal, Python, or server is needed. Your lesson progress and parts checklists are saved in that browser's localStorage on this device. They are not automatically shared with another browser or computer. Use each lesson's Reset progress button when you want to clear its saved checks.

If your browser blocks local files, use its Open File command and choose `START-HERE.html` from the extracted folder.
